# Real Estate Investment Advisor

A Streamlit app for exploring Indian housing listings and estimating property values.

**Live app:** [Open the Real Estate Investment Advisor](https://devvratwelekar-real-estate-investment-advisor-app-app-rqih5t.streamlit.app/)

## Run locally

Install Python 3.10 or newer, then run these commands in PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
.\run.bat
```

The app's estimates are based on the available dataset and are not guarantees of future property values or returns.
